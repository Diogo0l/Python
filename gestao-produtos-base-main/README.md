# Gestão de Produtos (Flask)

Sistema de gestão de produtos usado como **sistema sob teste** na UC3 do curso Programador de Sistemas (Senac).
Versão do projeto da UC2, agora em Flask: login, lista de produtos, cadastro de produto e registro de vendas com baixa de estoque.

## Como executar (rascunho)

1. Crie e ative um ambiente virtual.
2. Instale as dependências: `pip install flask pytest pytest-cov`.
3. Crie o banco: `python criar_banco.py`.
4. Crie um usuário: `python criar_usuario.py`.
5. Inicie: `flask --app app run --debug`.

Roteiro completo: `roteiros/01-instalar-e-executar.md`.
