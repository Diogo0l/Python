# Registro de defeitos

| ID | Título | Rota ou módulo | Passos para reproduzir | Esperado | Obtido | Severidade | Prioridade | Evidência | Status |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| DEF-01 |  |  |  |  |  |  |  |  | Aberto |

> **Severidade** = tamanho do impacto no sistema (alta, média, baixa). **Prioridade** = urgência de corrigir (alta, média, baixa).
> **Status:** Aberto, Em correção, Corrigido ou Verificado (teste de regressão passando).
> Se duas falhas têm a mesma causa, registre **um** defeito e liste as duas falhas na evidência.
