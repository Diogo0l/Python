# Exercício Biblioteca
## Cenário
Você está desenvolvendo um pequeno sistema para gerenciar uma biblioteca. Sua tarefa é criar funções que ajudem a organizar o acervo e o atendimentro aos usuários.

1. [x] Cadastro de Livro (Parâmetros Padrão)
    - Crie uma função chamada cadastrar_livro que receba título, autor e disponível (com valor padrão TRUE). A função deve retornar uma string formatada com os dados do livro.

2. [ ] Listagem de Livros (*args)
    - Crie uma função chamada listar_livros que receba um número variávelde títulos de livros e imprima cada um deles em uma linha.
